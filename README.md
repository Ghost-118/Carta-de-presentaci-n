# 📇 Tarjeta de Presentación Digital

Aplicación web interactiva que simula una tarjeta de presentación profesional. Proyecto desarrollado para cumplir con las historias de usuario y certificaciones del laboratorio de **freeCodeCamp**.

## 🚀 Características

* **HTML5 Semántico:** Estructura limpia y accesible utilizando etiquetas semánticas (`<div>`, `<p>`, `<a>`, `<img>`, etc.).
* **Diseño Personalizado con CSS3:** Estilizado moderno en tonos oscuros/tecnológicos, con esquinas redondeadas, sombras y maquetación centrada.
* **Sección de Contacto y Redes:** Enlaces directos a portafolio, perfil de LinkedIn y repositorio de GitHub.
* **Diseño Responsivo baisco:** Ajustado mediante propiedades de ancho y márgenes automáticos.

## 🛠️ Tecnologías Utilizadas

* **HTML5**
* **CSS3**

## 💻 Vista Previa

Para ver el proyecto en funcionamiento, simplemente abre el archivo `index.html` en cualquier navegador web.
